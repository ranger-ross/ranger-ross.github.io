## File structure

```tree
├── config.toml              # Site configuration
├── content/
│   ├── _index.md            # Home page
│   ├── resume.md            # Resume page with embedded PDF and download link
│   ├── blog/                # Blog posts
│   │   ├── hello.md         # Sample post
│   │   └── _index.md        # Blog section configuration
│   └── projects/            # Projects page
│       ├── cool_project.md  # Sample project
│       └── _index.md        # Projects section configuration
│── static/
│   ├── resume/
│   ├── resume.css           # Responsive PDF preview styles
│   └── img/
│       └── profile.webp     # Profile photo for home page
└── themes/
    └── tabi/                # tabi theme
```
